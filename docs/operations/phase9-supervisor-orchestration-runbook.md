# Phase 9 Supervisor Orchestration Runbook

## Purpose
Phase 9 turns the already-built Phase 1–8 supervisor components into one auditable daily production loop.

Outputs include:
- durable orchestration run rows in `supervisor_runs`
- per-step ledger rows in `supervisor_run_steps`
- latest health, market-state, recommendation, policy, paper-portfolio, and daily-brief artifacts generated by one runner
- one Nomad job for the scheduled daily cycle

## Daily job
- Nomad job: `deploy/nomad/jobs/vietmarket-supervisor-daily-cycle.nomad.hcl`
- Entrypoint: `python3 /src/packages/supervisor/orchestration/run_supervisor_cycle.py --mode daily --strict-health-gate`
- Schedule: `35 15 * * 1-5`
- Time zone: `Asia/Ho_Chi_Minh`

## Manual execution
```bash
export PG_URL='postgres://...'
python3 packages/supervisor/orchestration/run_supervisor_cycle.py --mode daily --strict-health-gate
```

## Verification
```bash
export PG_URL='postgres://...'
bash scripts/verify_phase9_supervisor_orchestration.sh
bash scripts/verify_phase9_nomad_supervisor_children.sh
```

Healthy result should show:
- latest `supervisor_runs.status = complete`
- latest `supervisor_run_steps` rows all `complete`
- latest `market_state_cycles` row refreshed
- latest `portfolio_snapshots` row refreshed
- latest `daily_briefs` row refreshed
- latest Nomad forced child is `dead` with alloc `Client Status = complete` and `Exit Code = 0`

Blocked result is acceptable under strict health gate if freshness/health is not healthy:
- `supervisor_runs.status = blocked`
- downstream recommendation / portfolio / brief steps marked `skipped`
- no autonomous action is taken

Failure result requires investigation:
- `supervisor_runs.status = failed`
- one or more `supervisor_run_steps.status = failed`
- inspect the corresponding `raw_output` from `supervisor_run_steps`
- inspect matching `worker_runs` / `worker_failures`

## Nomad rollout
```bash
nomad job plan deploy/nomad/jobs/vietmarket-supervisor-daily-cycle.nomad.hcl
nomad job run deploy/nomad/jobs/vietmarket-supervisor-daily-cycle.nomad.hcl
```
